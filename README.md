# Isotopic Studios website

Static site for [isotopicstudios.co.uk](https://isotopicstudios.co.uk), served by GitHub Pages from `main`.

- `index.html` – the whole site (plain HTML/CSS/JS, no build step)
- `assets/` – game art, store badges, Pub Crawl poster
- `512Icon.png` – studio logo / favicon

Preview locally: open `index.html` in a browser, or `python3 -m http.server`.
